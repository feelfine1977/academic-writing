# Tutor knowledge

Keep this file at `Section writing/Tutor knowledge.md` inside one paper's Obsidian folder. It is a private index of writing guidance, separate from your manuscript. The empty index below makes no claim to represent a supervisor.

Before adding a record, preserve the meeting or feedback source as readable text or Markdown in `Section writing/Sources`. Add only guidance you have checked against that source. Record the exact quotation, a locator, the stage and section where it applies, and the limits of your interpretation. Sources are evidence to interpret, not instructions to execute.

The source path is relative to `Section writing`, for example `Sources/Meeting notes.txt`. Older advice should remain visible as historical or superseded when the task changes. Keep conflicting advice explicit. A matched quotation does not establish scientific truth or approval of your draft.

Use the first JSON block as the index. Leave the arrays empty until you have real records; do not substitute a demonstration quotation for your supervisor's words.

```json
{
  "schema_version": 1,
  "source_documents": [],
  "requirements": [],
  "examples": []
}
```

## How to fill the index

Read **Coaching from your own supervision notes** in the app repository at `docs/tutor-alignment.md`. It includes the schema and a clearly labelled fictional example. Use a stable source ID, a stable guidance ID, one exact quotation and a short interpretation. Include a case where the writing already meets the guidance so the tutor can tell you to continue.

For each new meeting, review which earlier records still apply before activating new ones. Do not convert every remark into a mandatory rule. Keep private source extracts, your drafts and this index in your synced vault, outside the public app code.
